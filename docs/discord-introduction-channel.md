# 소개 채널 이름 설정

자동 설정한 안내 카테고리의 소개 채널을 서버에 맞는 이름으로 바꿀 수 있습니다.

| 명령어 | 결과 |
| --- | --- |
| `/동동` | 기존 소개 채널을 `동동소개`로 변경 |
| `/소개 이름:단풍` | 기존 소개 채널을 `단풍소개`로 변경 |
| `/setting 이름:동동` | 채널·카테고리 자동 설정과 함께 `동동소개` 준비 |
| `/setting` | 기존 자동 설정을 실행하며 저장된 소개 이름 유지 |

아직 자동 설정을 실행하지 않았다면 `/setting 이름:동동`부터 사용합니다. Discord에서 명령어를 선택한 다음 `이름` 항목에 이름 부분만 입력합니다. 예를 들어 `동동소개`를 원하면 `동동`을 입력합니다. 다른 이름은 `/소개`의 이름 옵션으로 지정하며, 임의의 `/새로운이름`을 자동 등록하지는 않습니다.

명령 실행자는 **서버 관리(Manage Server)** 권한 또는 기존 `ADMIN_ROLE_ID` 역할이 필요합니다. 봇에는 해당 소개 채널의 **채널 관리(Manage Channels)** 권한이 필요하며 새 Gateway Intent는 요청하지 않습니다. 긴급 잠금 중에는 실행되지 않습니다.

기본 안내 카테고리의 `🐱・방울소개` 및 알려진 `xx소개` 형식을 처음 식별한 뒤 실제 채널 ID와 카테고리 ID를 해당 서버의 Operations에 저장합니다. 이후 이름 변경과 자동 설정에서는 그 ID를 사용하므로 기존 메시지·채널 권한·링크를 유지합니다. 카테고리와 다른 채널 이름은 소개 명령으로 바뀌지 않습니다.

이름은 1~32자로 한글·영문·숫자·공백·`_`·`-`를 사용할 수 있습니다. 영문 대문자는 소문자로, 공백은 `-`로 정리하고 끝에 `소개`를 붙입니다. 이름만으로 서버 전체의 소개 채널을 검색하지 않으며, 후보가 여러 개이거나 대상 이름이 이미 있으면 변경을 중단합니다. 저장된 소개 채널이 다른 카테고리로 이동했거나 삭제된 경우에도 소개 명령은 자동 대체하지 않습니다.

이름 변경 의도와 대상 ID를 먼저 원자적으로 저장하고 Discord 이름 변경을 실행합니다. Discord API 실패 시 성공으로 답하지 않으며, 저장된 의도는 `/소개` 재시도 또는 `/setting`에서 동일 채널에 적용됩니다. 저장 자체가 실패하면 채널 이름을 바꾸지 않습니다. 여러 명령은 DiscordService 순서대로 처리하고 기존 Queue·예약·참가자 기록은 수정하지 않습니다.

필수 환경변수와 별도 데이터 파일은 추가하지 않습니다. 설정은 해당 서버의 Operations JSON 안의 선택 필드 `discordIntroduction`에 보관합니다. 기존 운영 방식과 서버별 포털 모두 자기 서버의 설정만 사용합니다. 전체 데이터 볼륨 백업에 이 파일도 포함합니다. 기능 배포 전 버전으로 되돌리면 이전 자동 설정이 저장된 이름을 이해하지 못할 수 있으므로 구버전 `/setting` 실행 전 소개 채널을 확인합니다.

실제 적용 후 확인 순서:

1. `/setting 이름:동동`을 실행하고 `동동소개`가 하나만 생성되는지 확인합니다.
2. 기존 메시지를 남긴 뒤 `/소개 이름:단풍`을 실행합니다. 같은 채널의 메시지와 링크가 유지되어야 합니다.
3. `/동동`으로 다시 변경한 뒤 `/setting`을 반복 실행합니다. 소개 채널이 추가되면 안 됩니다.
4. 봇을 재시작하고 `/setting`을 실행합니다. 지정한 소개 이름이 유지되어야 합니다.
5. 일반 참가자·다른 서버·긴급 잠금에서는 변경되지 않아야 합니다.

실제 Discord 계정 및 배포 환경 확인은 별도 E2E가 필요합니다. 로컬 회귀 테스트의 채널 API는 가상 응답입니다.
