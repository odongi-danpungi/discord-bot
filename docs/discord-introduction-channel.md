# 자동 채널·카테고리 공통 이름 템플릿

/setting의 이름 입력란에 원하는 이름을 넣으면 XX소개 등 이름이 들어가는 자동 생성 항목의 XX 자리에 함께 적용합니다.

| 입력 | 소개 채널 | 안내 카테고리 |
| --- | --- | --- |
| /setting 이름:동동 | 동동소개 | 🔔 ᭄༄・동동! 안내방 |
| /setting 이름:시리 | 시리소개 | 🔔 ᭄༄・시리! 안내방 |
| /setting 이름:후리나기 | 후리나기소개 | 🔔 ᭄༄・후리나기! 안내방 |

이름은 자유 입력입니다. Discord에서 /setting을 선택한 뒤 이름 옵션에 시리 같은 이름 부분만 입력합니다. 고정 선택지는 없습니다.

이름을 쓰는 템플릿은 다섯 곳입니다.

| 템플릿 | 이름이 시리일 때 |
| --- | --- |
| XX소개 | 시리소개 |
| 🔔 ᭄༄・XX! 안내방 | 🔔 ᭄༄・시리! 안내방 |
| 🐱・XX2 | 🐱・시리2 |
| 🔔・XX | 🔔・시리 |
| XX・XXXX | 시리・시리시리 |

공지사항, 이용규칙, 방송 일정, 시참, 내전, 로그 등 공통 기능 이름은 그대로 사용합니다. 기존 템플릿의 아이콘과 장식은 유지합니다. 소개 채널은 입력한 이름 뒤에 소개를 붙입니다.

이미 자동 설정한 서버에서도 같은 명령어로 이름을 바꿀 수 있습니다. 동동으로 설정한 뒤 /setting 이름:시리를 실행하면 같은 채널·카테고리를 시리 이름으로 변경합니다. 기존 채널 ID·메시지·권한·링크를 유지하고, 다음 /setting이나 재시작 이후에도 마지막 공통 이름을 유지합니다.

소개 채널만 따로 바꾸려면 /소개 이름:단풍을 사용합니다. 이 경우 다른 템플릿의 공통 이름은 유지합니다. 다음에 /setting 이름:시리처럼 공통 이름을 명시하면 소개를 포함한 모든 이름 템플릿에 시리가 적용됩니다.

명령 실행자는 서버 관리(Manage Server) 또는 기존 ADMIN_ROLE_ID 역할이 필요합니다. 봇에는 변경 대상의 채널 관리(Manage Channels) 권한이 필요합니다. 긴급 잠금·복구·재시작·종료 대기에는 실행을 차단합니다. 새 환경변수나 Gateway Intent는 없습니다.

이름은 1~32자로 한글·영문·숫자·공백·_·-를 사용할 수 있습니다. 영문은 소문자로, 공백은 -로 정리합니다. 서버 전체의 이름을 일괄 치환하지 않고, 자동 설정에서 관리하는 논리 항목과 저장한 ID만 사용합니다. 이름 변경 전에 모든 대상의 종류·위치·중복·권한을 확인합니다. 이름 충돌이나 불명확한 후보가 있으면 첫 변경 전에 중단합니다.

Operations의 선택 필드 discordSetupTemplate에 공통 이름과 다섯 항목의 ID를 저장합니다. 이전 discordIntroduction 설정도 보존하고 기존 채널 ID를 재사용합니다. 실제 이름 변경 전에 목적과 ID를 원자 저장해 Discord 요청 실패 후 같은 ID로 재시도합니다. 저장 실패 시 Discord 변경을 시작하지 않습니다. 이미 완료된 외부 변경을 하나의 트랜잭션처럼 되돌리지는 않으며, 부분 변경 후 /setting을 다시 실행하면 저장된 목표 이름으로 수렴합니다.

처음 공통 이름을 저장하기 전에는 기존 기본 이름을 사용합니다. 공통 이름을 지정한 뒤 /setting을 실행하면 관리 대상의 이름을 저장한 템플릿으로 맞춥니다. 관리 ID가 삭제되거나 다른 카테고리로 이동한 경우에는 임의로 대체하지 않습니다. 전체 데이터 볼륨 백업에 Operations를 포함하고, 이전 버전으로 되돌린 뒤에는 구버전 자동 설정 실행 전에 이름과 중복 채널을 확인합니다.

배포 후에는 이름을 동동 → 시리 → 후리나기로 차례로 바꾸고 채널 수·ID·메시지가 유지되는지 확인합니다. 재시작 후 이름 없이 /setting을 실행해 마지막 이름이 유지되는지 확인합니다. 실제 Discord 계정 E2E는 별도로 필요하며, 로컬 테스트는 가상 채널 API를 사용합니다.
