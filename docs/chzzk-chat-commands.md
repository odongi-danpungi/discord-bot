# 채팅 명령어

- 스트리머: 포털 → CHZZK → 채팅 → 채팅 명령어. 사용 여부, 같은 명령어 다시 답하기 간격(3~300초), 기본 명령어 켜기/끄기, 직접 만든 명령어(최대 30개).
- 기본 명령어
  - `!대기`: 지금 대기 중인 참가자 수.
  - `!순번`: 보낸 시청자의 순서. 팔로워 인증으로 치지직 계정을 디스코드 계정과 연결한 시청자만 찾을 수 있고, 아니면 연결 안내를 답합니다. 보낸 사람 채널 ID는 메모리에서 연결 계정과 맞춰 보기만 하고 저장하지 않습니다.
  - `!명령어`: 쓸 수 있는 명령어 목록(100자까지).
- 직접 만든 명령어: 이름은 한글·영문·숫자 1~12자, 답장 100자, `{닉네임}`은 보낸 시청자 이름. 답장은 `!`로 시작할 수 없습니다(명령어끼리 서로 부르는 것을 막기 위해).
- 보내기: 공식 API `POST /open/v1/chats/send`(Scope "채팅 메시지 쓰기")로 연결한 방송 계정이 보냅니다. 1초에 한 번, 대기 5개까지(넘치면 버림), 429를 받으면 1분 쉽니다. 봇이 방금 보낸 문장은 다시 답하지 않습니다. 401·403이면 "채팅 쓰기 권한 필요"로 표시합니다.
- 준비: 치지직 개발자 센터의 앱 설정에서 "채팅 메시지 조회"와 "채팅 메시지 쓰기"를 켠 뒤 CHZZK → 방송 계정 연결을 다시 진행해야 새 권한이 토큰에 들어갑니다.
- 저장: `operations.json.chat-commands.json`에 설정과 명령어만 저장합니다. 채팅 내용·닉네임·보낸 사람은 저장하지 않고, 답장/건너뜀 횟수는 메모리에만 둡니다.
- 미리 보기: 같은 화면에서 채팅을 넣으면 봇의 답을 보여 줍니다. 치지직에는 보내지 않습니다.
- API: `GET/POST /api/chat-commands`, `POST /api/chat-commands/test`(운영자, `broadcast` 권한, CSRF·Idempotency-Key·긴급 잠금). 기능 숨기기 `chat-commands`.
- 이번에 하지 않은 것: `!신청`(채팅으로 참가 신청)은 정원·중복·마감 규칙과 연결돼 따로 정한 뒤 만듭니다.
- **PENDING**: 실제 치지직 채팅에서 명령어를 받고 답장이 올라가는지, 채팅 쓰기 권한 동의, 배포.
