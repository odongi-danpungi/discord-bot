# OBS 후원 알림

- 스트리머: 포털 → 방송 → OBS → OBS 후원 알림. 사용 여부, 알림 문구(60자, `{닉네임}`·`{금액}` 자리), 최소 금액(1~1,000,000치즈), 표시 시간(3~20초), 알림 소리, 후원 메시지 보이기.
- OBS: 브라우저 소스 `/w/:서버/broadcast/donation-alert?token=...`(방송 토큰), 투명 배경, 권장 800×300. 소리를 쓰려면 OBS 브라우저 소스에서 "OBS에서 오디오 제어"를 켭니다. 소리는 파일 없이 브라우저가 만든 짧은 효과음입니다.
- 동작: 연결한 방송 계정의 치즈 후원(공식 Session API, 다른 후원 기능과 같은 구독 하나)을 받아 한 번에 하나씩 보여 줍니다. 다른 채널 후원과 최소 금액 미만은 무시하고 개수만 셉니다.
- 저장: `operations.json.donation-alert.json`에는 설정만 저장합니다. 알림(닉네임·금액·후원 메시지)은 서버 메모리에 최근 30개만 두고 디스크에 쓰지 않습니다. 후원자 채널 ID는 이 기능에 전달되지 않습니다. 스트리머 화면의 최근 알림 목록에는 메시지를 보여 주지 않습니다.
- 테스트: 같은 화면의 "OBS 테스트". 최소 금액과 상관없이 보낼 수 있고 OBS에 `테스트` 표시가 붙습니다(1초에 한 번).
- API: `GET/POST /api/donation-alert`, `POST /api/donation-alert/test`(운영자, `broadcast` 권한, CSRF·Idempotency-Key·긴급 잠금 적용) · OBS 피드 `GET /broadcast/api/donation-alert`(방송 토큰).
- 기능 숨기기: `obs-alert`를 숨기면 위 API도 403입니다.
- **PENDING**: 실제 치지직 후원으로 알림이 뜨는지, 실제 OBS에서 소리가 나는지, 배포.
