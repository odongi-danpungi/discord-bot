# 실제 연결 확인 체크리스트 (PENDING 항목 정리)

로컬 테스트와 연습 모드는 실제 Discord·네이버·치지직 연결을 대신하지 못합니다. 아래 항목은 **배포된 서버에서 실제 계정으로** 확인해야 하고, 확인 전까지 PENDING입니다. 결과는 각 항목의 "기록"에 날짜와 함께 적습니다. 토큰·비밀번호·실제 채널 ID는 기록에 적지 않습니다.

## 0. 준비
- [ ] 배포 완료, `/healthz` 200 (`docs/hosting-options.md`)
- [ ] `npm run env:check` 통과, `PUBLIC_BASE_URL`이 HTTPS
- [ ] 운영 데이터 백업 1회 (운영 화면 → 백업)
- [ ] 테스트용 Discord 서버 1개 (가능하면 2개: 서버 A/B 분리 확인용)
- [ ] 참가자 역할을 할 두 번째 계정(Discord·네이버·치지직). 없으면 4·5번은 "참가자 계정 없음"으로 남깁니다.
- [ ] 치지직 후원 테스트 비용: 최소 금액 후원 몇 번(실제 치즈 사용)

## 1. 치지직 방송 계정 연결
- [ ] CHZZK → 방송 계정 연결 → 치지직 동의 화면 → 돌아와서 "연결됨"
- [ ] 후원 조회·채팅 조회 권한에 동의했는지 각 화면 배지로 확인("권한 동의 필요"가 아니어야 함)
- 기록:

## 2. 치즈 후원 (실제 1건으로 여러 기능을 한 번에)
설정: 후원 룰렛 켜기, OBS 후원 알림 켜기(첫 구간 최소 금액 = 테스트 금액 이하), OBS 후원 목표 켜기, 카드 뒤집기 치즈 기회 켜기, 뽑기판 켜고 새 판 만들기.
- [ ] OBS 후원 알림: OBS에 알림이 뜨고 닉네임·금액이 맞음, 소리가 OBS 오디오로 들림, 금액 구간별 그림·소리가 바뀜
- [ ] OBS 후원 목표: 후원 금액만큼 막대가 차오름
- [ ] 치즈 후원 룰렛: 금액 구간에 맞게 돌아감
- [ ] 뽑기판: 후원 메시지에 번호(예: `7`)를 적으면 그 칸이 열림. 번호가 없으면 보류 기회로 남음
- [ ] 카드 뒤집기: 팔로워 인증으로 연결된 시청자가 후원하면 기회가 들어옴, 연결 안 된 후원자는 들어오지 않음
- [ ] 저장 파일에 후원 메시지·후원자 채널 ID가 없는지 확인(`operations.json.*.json`에서 메시지 문구 검색)
- 기록:

## 3. 치지직 채팅
- [ ] OBS 채팅창에 실제 채팅이 뜨고 이모티콘 이미지가 보임
- [ ] 치지직 개발자 앱에 "채팅 메시지 쓰기" 권한을 켜고 방송 계정을 다시 연결
- [ ] 채팅 명령어: `!대기`, `!명령어`, 직접 만든 명령어에 봇이 답함, 같은 명령어 연속 입력 시 간격 동안 답하지 않음
- [ ] `!순번`: 팔로워 인증으로 연결된 계정은 순서, 연결 안 된 계정은 안내
- [ ] 채팅창 비우기 동작
- 기록:

## 4. Discord 참가 흐름
- [ ] `/setting 이름:...`으로 채널·카테고리 이름이 바뀜, 같은 명령을 다시 해도 중복 생성 없음
- [ ] 참가 모집 → 참가 신청 → 통합 Queue 표시 → 호출 → 응답(참가자 계정 필요)
- [ ] 참가 확정 후 카드 뒤집기 기회 1회(회차당 1번)
