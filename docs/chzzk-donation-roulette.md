# 치즈 후원 룰렛 (CHZZK 후원 → 룰렛)

상태: 코드·자동 테스트 완료, **실제 CHZZK 후원 수신 E2E는 PENDING**입니다. 구독 요청이 성공해도 화면에는 "실제 후원 수신 검증 대기"로 표시합니다.

## 동작

- 스트리머(운영자) 메뉴의 **방송 → 룰렛 → 치즈 후원 룰렛**에서 서버별로 설정합니다(`broadcast` 권한). 같은 중분류에 **직접 입력 룰렛**이 있습니다.
- 금액 구간 1~5개. 구간마다 최소 금액(1~100,000,000치즈)과 룰렛 항목 2~99개(항목당 1~30자, 공백 포함).
- 후원 금액이 해당하는 구간 중 **최소 금액이 가장 높은 구간 하나**를 사용합니다. 가장 낮은 구간보다 적은 후원은 무시합니다(횟수만 집계).
- 돌리는 방식
  - **후원 1건에 1회**(기본값, 이전 저장 설정도 이 방식)
  - **금액만큼 여러 번**: 사용한 구간의 최소 금액당 1회, 한 후원당 최대 1~10회. 예) 1,000치즈 구간에 3,500치즈 → 3회. 한 후원의 모든 회차는 한 번의 원자 저장으로 함께 확정되고, OBS에서는 "1/3회 → 2/3회 → 3/3회" 순서로 재생합니다.
- 결과는 기존 룰렛과 같은 방식으로 서버 암호학적 난수 → Operations 원자 저장 후 확정합니다. 룰렛 화면의 최근 기록(직접 입력 항목으로 표시)에 남고, 대기열 순서·상태는 바꾸지 않습니다.
- 후원 기록(최근 60건, 회차별로 1건씩)은 `operations.json.donation-roulette.json`에 따로 저장합니다. 후원자 닉네임(최대 20자)·금액·결과만 저장하고 **후원자 채널 ID·후원 메시지는 저장하지 않습니다.**
- 긴급 잠금·안전 종료·릴리스 적용 중에는 룰렛을 돌리지 않고 "돌리지 않음" 사유를 기록합니다. 처리 대기 후원이 50건을 넘으면 넘친 후원도 같은 방식으로 기록합니다.
- 연결한 방송 계정이 아닌 다른 채널의 후원 이벤트는 무시합니다.

## 테스트 후원

- 설정 화면의 **테스트 후원**에 닉네임과 금액을 넣으면 저장된 구간·돌리는 방식 그대로 결과를 만들어 후원 기록과 OBS에 보여 줍니다.
- 치지직 연결이나 "사용" 설정 없이 동작하며, 기록과 OBS에는 **[테스트]**로 표시됩니다. 룰렛 기록·운영(Operations) 기록에는 남기지 않습니다.
- 3초에 한 번만 보낼 수 있고, 긴급 잠금 중에는 거절됩니다. 운영자(`broadcast` 권한)만 사용할 수 있습니다.

## OBS

- 방송 → OBS → **OBS 룰렛**(추가 방법 안내) 또는 룰렛 → 치즈 후원 룰렛 → **OBS 후원 룰렛 주소 복사** → OBS 브라우저 소스(권장 1280×720, 배경 투명)에 붙여 넣습니다.
- 주소는 서버별 방송 토큰으로 보호됩니다. 다른 서버의 토큰으로는 열리지 않습니다. 참가자에게 공유하지 마세요.
- 화면을 열 때 이미 있던 기록은 다시 재생하지 않고, 이후 새로 저장된 결과만 "닉네임님 N치즈 → 결과" 순서로 재생합니다(움직임 줄이기 설정 시 회전 없음).

## CHZZK 연결 방식 (공식 Session API)

1. `GET /open/v1/sessions/auth` — 방송 계정(소유자) Access Token으로 유저 세션 주소 발급
2. Socket.IO 2.x 호환(Engine.IO v3) WebSocket 연결 — 별도 패키지 없이 Node 내장 WebSocket 사용
3. `SYSTEM connected`의 `sessionKey`로 `POST /open/v1/sessions/events/subscribe/donation` (필요 Scope: **후원 조회**)
4. `DONATION` 이벤트 수신 → 룰렛
- 재연결: 2초부터 최대 60초 지수 대기. 권한 회수(`revoked`)·401/403은 "후원 조회 권한 동의 필요"로 표시하고 5분 간격으로만 재시도합니다.
- 후원과 채팅(OBS 채팅창)은 서버마다 **하나의 CHZZK 유저 세션**을 함께 사용합니다(CHZZK는 계정당 유저 세션 3개까지 허용). 한쪽 권한이 없어도 다른 쪽 구독은 유지합니다. 사용하는 기능이 바뀌면 세션을 다시 만들며 이때 몇 초간 이벤트가 끊길 수 있습니다.
- 방송 계정 토큰은 기존 CHZZK 연결 저장소(암호화)와 갱신 로직을 그대로 사용합니다. 새 비밀값·환경변수는 없습니다.

## PENDING (사용자 확인 필요)

1. CHZZK 개발자센터 앱에 **"후원 조회" Scope**가 켜져 있어야 합니다. 켠 뒤 각 서버에서 CHZZK → 방송 계정 연결을 **다시 동의**해야 기존 토큰에 권한이 생깁니다.
2. 공식 문서에 `sessionKey`가 "Request Param"으로만 표기되어 있어 쿼리 파라미터로 보냅니다. 실제 호출에서 400이 나오면 본문 전달로 바꿔야 할 수 있습니다.
3. 공식 후원 이벤트에는 고유 ID·시각 필드가 없습니다. 같은 후원이 중복 전달되지 않도록 서버별로 세션을 1개만 유지하지만, 실제 중복 전달 여부는 방송에서 확인해야 합니다.
4. 실제 방송에서 테스트 후원 → 운영 화면 기록 → OBS 재생까지 확인 후 PENDING을 해제하세요.
