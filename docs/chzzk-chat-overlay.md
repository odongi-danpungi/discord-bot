# OBS 채팅창 (CHZZK 채팅 → OBS)

상태: 코드·자동 테스트 완료, **실제 CHZZK 채팅 수신 E2E는 PENDING**입니다. 구독 요청이 성공해도 화면에는 "실제 채팅 수신 검증 대기"로 표시합니다.

## 위치
- 스트리머(운영자) 메뉴 **방송 → OBS → OBS 채팅창** (`broadcast` 권한). 같은 중분류에 **OBS 룰렛**(치즈 후원 룰렛을 OBS에 넣는 방법 안내)이 있습니다.

## 동작
- 서버별 설정: 사용 여부, 한 번에 보일 채팅 수(3~20), 사라지는 시간(15초·30초·1분·2분·5분·사라지지 않음), 글자 크기(작게·보통·크게). 저장 파일 `operations.json.chat-overlay.json`, revision 충돌 검사.
- 연결한 방송 계정의 채널 채팅만 표시합니다. 다른 채널 이벤트는 무시합니다.
- 채팅 내용은 **디스크에 저장하지 않습니다.** 서버 메모리에 최근 50개만 두고, 재시작하면 비워집니다. 보낸 사람 채널 ID·채팅 채널 ID는 받자마자 버리고 닉네임(20자)·역할(스트리머/매니저/시청자)·내용(300자)·CHZZK 이모티콘만 씁니다.
- 이모티콘 이미지는 `https://*.pstatic.net` 주소만 사용하며, 이 이미지 허용(CSP)은 OBS 채팅창 페이지에만 적용됩니다.
- **테스트 채팅**: 치지직 연결·사용 설정 없이 "테스트" 표시가 붙은 채팅을 보냅니다(1초에 1번).
- **채팅창 비우기**: OBS 화면과 메모리의 채팅을 지웁니다(원치 않는 채팅이 떴을 때).
- 운영 잠금 중에는 테스트·비우기·설정 저장이 거절됩니다.

## OBS
- **OBS 채팅창 주소 복사** → OBS 소스 + → 브라우저 → URL 붙여넣기, 권장 400×600, 배경 투명.
- 주소는 서버별 방송 토큰으로 보호됩니다. 다른 서버 토큰으로는 열리지 않습니다. 참가자에게 공유하지 마세요.
- OBS 화면은 1초마다 새 채팅을 가져옵니다(실패 시 최대 15초까지 간격을 늘림).

## CHZZK 연결 (공식 Session API)
1. 치즈 후원 룰렛과 **같은 유저 세션**을 씁니다(`ChzzkSessionHub`). CHZZK는 계정당 유저 세션을 3개까지 허용합니다.
2. `SYSTEM connected`의 `sessionKey`로 `POST /open/v1/sessions/events/subscribe/chat` (필요 Scope: **채팅 메시지 조회**)
3. `CHAT` 이벤트 수신 → 채팅창
- 채팅 권한만 없으면 "채팅 메시지 조회 권한 동의 필요"로 표시하고 후원 구독은 유지합니다. 방송 계정을 다시 연결(동의)하면 세션을 새로 만듭니다.

## PENDING (사용자 확인 필요)
1. CHZZK 개발자센터 앱에 **"채팅 메시지 조회" Scope**를 켜고, 각 서버에서 CHZZK → 방송 계정 연결을 **다시 동의**하세요.
2. 실제 방송에서 채팅 → OBS 채팅창 표시, 이모티콘 이미지 표시(pstatic 주소 여부)를 확인한 뒤 PENDING을 해제하세요.
3. 같은 방송 계정을 여러 Discord 서버에 연결하면 서버마다 세션 1개를 씁니다. 4개 이상 서버에서 동시에 쓰면 CHZZK 세션 제한에 걸릴 수 있습니다.
4. 채팅 삭제(관리자 가리기) 이벤트는 공식 API에 없어 OBS에서 자동으로 사라지지 않습니다. 필요하면 **채팅창 비우기**를 쓰세요.
